# Zerqon Spider

**Crawl Deeper. Discover More.** — Advanced SEO Crawler & Auditor

Zerqon Spider, sahibi olduğunuz veya tarama izniniz bulunan web sitelerini tarayıp teknik SEO sorunlarını
kanıtlarıyla tespit eden, önceliklendiren ve raporlayan yerel (local-first) bir uygulamadır.

> 🚧 Geliştirme sürüyor. Kapsamlı dokümantasyon Aşama 6'da tamamlanacaktır.
